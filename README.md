# meilleur-poele-granules.fr

Guide indépendant du chauffage au granulé de bois.

## Plomberie

- Site statique, déployé sur **Cloudflare Pages** (projet `meilleur-poele-granules`)
- `.github/workflows/deploy.yml` : déploiement à chaque push et à la demande
- `.github/workflows/seo-article.yml` : un article les lundi, mercredi et vendredi,
  mot-clé pioché dans `_seo/keywords.txt`
- `_seo/keywords.txt` : **164 sujets** extraits de l'archive Semrush du 16/08/2026,
  filtrés (difficulté ≤ 30, volume ≥ 200) puis dédoublonnés par racinisation.
  Sans cette racinisation, 152 variantes auraient produit autant d'articles
  qui se cannibalisent.

## Règles

- Publier sous le persona **Damien Roux**, jamais sous le nom de Pascal.
- Zéro tiret cadratin, zéro emoji dans le contenu publié.
- Le texte publié doit être **accentué** correctement, FAQ comprise.
- Aucun lien affilié tant que la page /a-propos/ annonce qu'il n'y en a pas.
  Si cela change, mettre à jour la page **avant** de poser le premier lien.
